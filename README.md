# 쇼핑몰 한번에 검색

검색어 하나로 가격비교·오픈마켓·종합몰·전문몰 21곳의 **검색 결과 페이지를 한 번에 여는** 개인용 페이지.
가격을 가져오거나 저장하지 않고, 각 쇼핑몰 검색 주소로 연결만 한다. API 키·서버가 필요 없다.

## 사용법

1. `index.html` 을 더블클릭해서 연다.
2. 검색어를 입력하고 **Enter** → 오른쪽에 결과 창이 **하나** 뜨고 첫 쇼핑몰 검색 결과가 보인다.
3. **◀ 이전 / 다음 ▶**(또는 ← → 키)로 같은 창에서 쇼핑몰을 넘겨 본다. 쇼핑몰 이름을 누르면 그곳으로 바로 간다.
   - 따로 새 탭으로 보고 싶으면 Ctrl+클릭한다.
   - 한꺼번에 탭으로 열고 싶으면 "모두 새 탭으로 열기"를 쓴다(팝업 "항상 허용" 필요).
4. 카테고리(식품·생활·뷰티·가구·패션·가전)를 고르면 그 분야를 다루는 쇼핑몰만 남는다.
5. 안 쓰는 쇼핑몰은 체크를 풀어 둔다. 체크 상태와 최근 검색어는 브라우저에 기억된다.

## 휴대폰에서 앱처럼 쓰기

https://zenki798.github.io/mall-search/ 를 열고 홈 화면에 추가하면 주소창·툴바 없이 앱처럼 뜬다.

- **안드로이드(크롬)**: 화면 위의 "앱으로 설치" 버튼, 또는 메뉴(⋮) → "홈 화면에 추가"/"앱 설치"
- **아이폰(사파리)**: 아래쪽 공유 버튼(□↑) → "홈 화면에 추가"

앱에서는 넘겨보기를 누르면 쇼핑몰이 앱 위에 한 곳씩 열린다. 닫기(✕)로 돌아와 "다음 ▶"을 누르면 다음 쇼핑몰이 열린다.

## 개발

```bash
npm install
npx playwright test          # 전체 테스트 (외부 사이트 접속 없음)
npm run check:links          # 쇼핑몰 검색 주소가 실제로 열리는지 확인 (네트워크 필요)
npm run make:icons           # 앱 아이콘 PNG 다시 만들기
```

쇼핑몰 추가·수정 방법과 주의점은 [AGENTS.md](AGENTS.md) 3항에 있다.
