# 쇼핑몰 한번에 검색

검색어 하나로 가격비교·오픈마켓·종합몰·전문몰 21곳의 **검색 결과를 이 페이지 안에서 차례로 넘겨 보는** 개인용 페이지.
가격을 가져오거나 저장하지 않고, 각 쇼핑몰 검색 결과 페이지를 보여 주거나 연결만 한다. API 키·서버가 필요 없다.

## 사용법

1. https://zenki798.github.io/mall-search/ 를 연다 (또는 `index.html` 을 더블클릭).
2. 검색어를 입력하고 **Enter** → 첫 쇼핑몰 검색 결과가 **이 페이지 안에** 뜬다.
   - PC·태블릿 가로(아이패드 등): 왼쪽은 쇼핑몰 목록, 오른쪽은 결과. 휴대폰·태블릿 세로: 결과가 화면 전체에 뜬다.
3. **◀ / 다음 ▶**(PC 는 ← → 키도)로 넘겨 본다. 쇼핑몰 이름을 누르면 그곳으로 바로 간다.
   - 닫기: ✕, Esc(PC), 뒤로 가기(휴대폰)
   - 로그인·장바구니나 더 크게 보고 싶을 때: **↗ 새 창**
4. **"새 창" 표시가 붙은 곳**(네이버쇼핑·에누리·쿠팡·G마켓·옥션·11번가·올리브영·오늘의집·이케아)은 쇼핑몰이
   다른 사이트 안에 표시되는 것을 막아 두어서 새 창으로 열린다. 넘겨보기에서는 기본으로 건너뛰고,
   결과 화면 위쪽의 "새 창 전용 …도 넘겨보기에 포함"을 켜면 순서에 들어간다.
   - 쇼핑몰이 새로 막으면 **매일 아침 자동 점검**이 알아채서 그 쇼핑몰을 새 창으로 바꾼다(다시 허용하면 되돌린다).
5. 카테고리(식품·생활·뷰티·가구·패션·가전)를 고르면 그 분야를 다루는 쇼핑몰만 남는다.
6. 안 쓰는 쇼핑몰은 체크를 풀어 둔다. 체크 상태·최근 검색어·"포함" 설정은 브라우저에 기억된다.
7. 한꺼번에 탭으로 열고 싶으면 "모두 새 탭으로 열기"(PC, 팝업 "항상 허용" 필요).

## 휴대폰에서 앱처럼 쓰기

위 주소를 열고 홈 화면에 추가하면 주소창·툴바 없이 앱처럼 뜬다.

- **안드로이드(크롬)**: 화면 위의 "앱으로 설치" 버튼, 또는 메뉴(⋮) → "홈 화면에 추가"/"앱 설치"
- **아이폰(사파리)**: 아래쪽 공유 버튼(□↑) → "홈 화면에 추가"
- **아이패드(사파리)**: 오른쪽 위 공유 버튼(□↑) → "홈 화면에 추가"

앱에서도 결과는 앱 안에서 넘겨 본다. "새 창" 쇼핑몰만 앱 위에 겹쳐 열리고, 닫으면 앱으로 돌아온다.

## 개발

```bash
npm install
npx playwright test          # 전체 테스트 (외부 사이트 접속 없음)
npm run check:links          # 쇼핑몰 주소가 열리는지 + 페이지 안에 표시되는지 확인 (네트워크 필요)
npm run check:frames         # 막힘 자동 점검을 직접 돌리기 (data/frame-status.js 갱신 — 보통은 GitHub 이 매일 한다)
npm run make:icons           # 앱 아이콘 PNG 다시 만들기
```

쇼핑몰 추가·수정 방법과 주의점은 [AGENTS.md](AGENTS.md) 3항에 있다.
