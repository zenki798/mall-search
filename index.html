쇼핑몰 한번에 검색

검색어 하나로 가격비교·오픈마켓·전문몰의 검색 결과를 차례로 넘겨 봅니다.

넘겨보기(Enter)는 체크한 쇼핑몰의 검색 결과를 이 페이지 안에서 ◀ ▶ 로 차례로 보여 줍니다. 쇼핑몰 이름을 누르면 그곳으로 바로 가고, Ctrl+클릭하면 새 탭으로 열립니다.
새 창 표시가 붙은 곳(네이버쇼핑 등)은 쇼핑몰이 다른 사이트 안에 표시되는 것을 막아 두어서 새 창으로 열립니다. 로그인·장바구니도 새 창(↗)에서 쓰는 것이 확실합니다.
모두 새 탭으로 열기는 체크한 곳을 한꺼번에 여는데, 브라우저가 팝업을 막으면 첫 탭만 열립니다. 이때 주소창 오른쪽의 팝업 차단 아이콘에서 "항상 허용"을 고르고 다시 누르세요.
이 페이지는 가격을 가져오거나 저장하지 않습니다. 각 쇼핑몰 검색 주소로 연결만 합니다.
← → 키로 넘기고 Esc 로 닫습니다.
불러오는 중…
검색 결과가 이 화면 안에 보이는지 아직 확인하지 못했습니다. 결과 대신 "연결을 거부했습니다"·"사용 권한이 없습니다" 같은 오류 화면이 보이면 위의 ↗ 새 창을 누르세요.

검색 결과는 이 화면 안에 표시할 수 없습니다.
쇼핑몰이 다른 사이트 안에 표시되는 것을 막아 두었습니다.

다음 ▶ 을 누르면 다음 쇼핑몰로 넘어갑니다.
